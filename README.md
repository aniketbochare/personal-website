# Aniket Bochare — Personal Website

Personal portfolio site for Aniket Bochare: Senior Engineering Manager · Technical Architect & Leader — GenAI & Conversational AI Platforms.

Live site: https://muse.ai/s/personal-website-xbxa6xvxim1a4pxr/vEkCYGtjURVw8wqBH8VvMXRFqWnlL0L_Ieltmuj6818

## Structure

- `index.html` — the complete single-page site (Executive Dark theme: deep navy/charcoal with gold accents)
- `assets/aniket-bochare-headshot.png` — profile photo used in the hero

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## GitHub Pages

This repo can be served directly with GitHub Pages (Settings → Pages → deploy from `main`, root folder).
